# Mountain SOS Navigation App

Таулы және байланыс әлсіз немесе жоқ аймақтарда қауіпсіз қозғалуға арналған мобильді қосымша. Қосымша офлайн карталар мен маршруттар арқылы бағдарлануға мүмкіндік береді және төтенше жағдайда координаттармен бірге SOS көмек сигналын жібереді. Туристерге, альпинистерге, нұсқаушыларға және құтқару қызметтеріне арналған.

## Мақсаты
Таулы аймақтардағы пайдаланушыларды офлайн навигациямен қамтамасыз ету және төтенше жағдайда геокоординаттарды жедел жіберу арқылы көмек шақыру тиімділігін арттыру.

## Пайдаланушылар
- Турист / Альпинист
- Маршрут нұсқаушысы
- Құтқару қызметінің операторы
- Жүйе әкімшісі

## Талаптар
1. Пайдаланушы таулы аймақтың офлайн картасын және сақталған маршруттарды интернетсіз ашады.
2. Қосымша GPS арқылы ағымдағы координаттарды, биіктікті және қозғалыс бағытын нақты уақытта көрсетеді.
3. Пайдаланушы төтенше жағдайда SOS батырмасын басып, көмек сигналын іске қосады.
4. Жүйе ағымдағы GPS координаттарын, уақытын және батарея деңгейін тіркеп, сигналды құтқару орталығына жібереді.
5. Мобильді интернет болмаған жағдайда жүйе SMS немесе спутниктік/резервтік арна арқылы жіберуді қолдайды.
6. Жүйе құтқару орталығынан келген растау мәртебесін пайдаланушы экранында көрсетеді.
7. Құтқару операторы түскен SOS өтінімдерін картадан көріп, мәртебесін жаңартады.
